Build a collaborative whiteboard web application like Excalidraw Pro.

Features:
1. A whiteboard canvas where users can draw shapes (rectangle, circle, arrows), write text, and freehand draw.
2. Real-time collaboration with multiple users editing the same board using WebSockets or WebRTC.
3. Toolbar with tools: select, draw, text, shapes, color picker, undo/redo, zoom in/out.
4. Save and load whiteboards to/from cloud storage (e.g., Firebase or a local database).
5. User authentication (login/signup) with role-based access (viewer, editor).
6. Export board as PNG, SVG, or JSON.
7. End-to-end encryption of whiteboard data.
8. Responsive UI for desktop, tablet, and mobile.
9. Workspaces where users can organize and share boards.
10. Version history for each whiteboard.

Use React for frontend and Node.js/Express with WebSocket support for the backend.
Use TailwindCSS for styling.
